**이 작업에 적용할 규칙**
- 개선안을 쓰기 전에 실패 모드 카탈로그(10개 이상, 확률×영향 등급 포함)부터 완성한다.
- 순번 표시를 바꾸기 전에 쓰고 있는 ILS가 순번을 어떻게 계산하는지(선착순 여부, 일시정지 건너뛰기, 이용 가능 예약 제외 여부) 먼저 확인한다. SirsiDynix Symphony는 선착순이 아닐 수 있다.
- 예상 대기 표시에서는 "안내보다 늦게 받는 경험"을 1순위 실패 모드로 둔다. 안내한 시간보다 오래 기다리면 이탈이 급증한다는 실증 결과(Webb 외)가 있다.
- 모든 변경 항목을 Type 1과 Type 2로 분류하고, Type 2는 파일럿과 롤백으로 빨리 돌리고 Type 1만 사전 검토를 거친다.
- 파일럿마다 시작 전에 킬 기준(기한·지표·임계값)을 문서로 고정한다.
- "정보를 더 많이 보여주면 이용자 만족이 오른다"는 합의를 그대로 믿지 말고 반증 실험 대상으로 올린다.
- 불만 하나하나를 표시 / 정책 / 공급(장서·라이선스) 중 하나로 분류하고, 표시가 아닌 원인은 계획 범위 밖이라고 명시한다.
