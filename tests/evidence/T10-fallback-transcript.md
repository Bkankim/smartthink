**노쇼율 정의(고정)**: `노쇼율 = 유예 시간 내 미인증(미입실) 건수 / 예약 확정 건수`. ULiège의 22%→13%는 점유율 78%→87%와 합이 100%라 "1 - 점유율" 정의인데, 점유율 분모가 예약 건수라면 위 정의와 같고 전체 좌석-시간이라면 다르다. 팩 3절로는 분모를 확정할 수 없으므로 **ULiège 수치는 방향과 폭(상대 감소 41%, 산출: (22-13)/22)의 참고값**으로만 쓰고, 시범 관 기준선은 위 정의로 새로 측정한다. 프로그램 노쇼는 `미출석 건수 / 확정 신청 건수`, 자료 예약 노쇼는 `보관 기한 만료 미수령 건수 / 도착 통보 건수`로 각각 따로 둔다. 세 영역 노쇼를 합산하지 않는다.

**관점 B. 인지 무기고 진단: 현행 안내의 문제 구조**

- **최소 작용(#10) - 단계 수**: 프로그램 신청 경로(오산) "교육포털 > 교육신청 > 도서관 선택 > 선택교육보기 > 신청하기" = 5단계. 도서관 홈페이지에서 진입했는데 다시 도서관을 선택하는 단계는 정보 없이 마찰만 있는 단계다. 목표 3단계(강좌 목록 → 상세 → 신청). 좌석은 예약 → 입실 인증 2단계이며 **인증 단계는 유지**한다(노쇼 감소 근거가 있는 유일한 단계). 자료 예약은 예약 → 도착 알림 수신 → 방문인데 "알림 수신"이 이용자 통제 밖의 단계라 여기서 끊긴다.
- **메커니즘 디자인(#24) - 호소 vs 메커니즘**: 현행 규칙이 유도하는 실제 행동을 적으면, "3회 미처리 7일 정지"는 3회 전까지 노쇼가 무비용이므로 2회까지는 예약 후 방치를 유도한다. "외출 1시간 30분"은 1시간 29분 외출을 정상 행동으로 만든다. "반드시 취소해 주세요"·"신중한 신청 부탁"은 메커니즘이 아니라 호소다. Nashville의 "노쇼를 일일 한도에 산입"은 노쇼 1회부터 비용이 생기는 메커니즘이고, 정지가 아니라 소진이어서 고령층 이용정지 누적 문제도 피한다. 공공 병기 완료(Nashville·LA County).
- **프레이밍(#35)**: 죽전 "30분 이내 인증"은 경고인지 자동퇴실인지 문장만으로 알 수 없다. 현행 안내는 규정 조문 프레임이다. 행동 프레임으로 바꾸면 "예약 후 30분 안에 좌석 단말에 인증하세요. 하지 않으면 예약이 자동 취소되고 다음 대기자에게 넘어갑니다"가 된다. 정보량은 같고 이용자의 다음 행동이 하나로 정해진다.
- **피크엔드(#37)**: 예약 여정의 피크는 확정 순간(안도), 엔드는 노쇼·취소 통보 순간(부정). 자원을 엔드에 몰아야 한다. 통보 문구에 "이번 달 남은 예약 가능 횟수 N회"(손실 회피 #31, 잃지 않는 것 프레임)를 붙인다. 단 "지금 안 하면 영구 정지" 류 가짜 긴급성은 공공 신뢰를 파괴하는 안티패턴이라 금지.
- **상대성(#7)**: 이용자는 도서관 안내를 병원 예약(문자 1회, 취소 링크 1개)과 영화관 예매(좌석도, 취소 마감 시각 명시)의 기준 프레임으로 읽는다. "5~20분(관별 상이)"은 그 프레임에서 "모른다"와 같다.
- **바퀴벌레 이론(#20)**: "F5 새로고침" 공지 1건은 접속 폭주 민원이 공지에 반영될 만큼 반복됐다는 확인된 징후다. 추정 규모는 3절에 공공 불만 통계가 없어 산정 불가 - "확인된 징후 1건, 규모 미측정"으로 표기한다.
- **오컴(#59)**: 관별 규칙을 그대로 두고 안내만 통일하려는 후보는 "관별 상이" 각주를 늘려 복잡성을 더한다. 규칙 통일이 안내 통일의 전제다.
- **한계효용(#47)**: 리마인더 2회차부터 효용이 음(25.9% 중복 판단). 확정 문자 1회에 규칙 3줄과 취소 링크를 넣는 것이 상한이다.
- **OODA 자가 진단(운영 병목)**: 관찰(노쇼 데이터가 담당자에게 언제 도달하나 - 시나리오 A는 미집계), 정향(월간인가 주간인가), 결정(문구 변경 승인 단계 수), 실행(홈페이지 수정이 벤더 요청인가 자체인가). **승인이 3단계 이상이면 안내 개선보다 "문구·게시물은 팀 자율" 권한 매트릭스가 먼저다.** 이 진단 자체가 첫 주 행동이다.

5단계 이중 트랙(#55):
- 낙관 편향: 대학의 41% 상대 감소를 공공에 그대로 기대하는 것. 보고서의 목표치는 그 절반(-20%)으로 잡고, 이것도 "목표"이지 "예측"이 아니라고 명시한다.
- 확증 편향: 화면 개선을 지지하는 증거만 채택하는 것. 3절 증거는 오히려 반대 방향(리마인더 제거가 지지받음)이다. Top 3에 화면 전용 후보는 1개만 둔다.
- 매몰비용: 기존 벤더 계약 유지 압력. 벤더 교체는 어느 후보에도 넣지 않고 설정 변경 범위 안에서 설계한다. 벤더가 자동 승계를 지원하지 않으면 수동 SMS(Wizard of Oz)로 우회한다.

#### 2.5 교차 엔진 합성

- **제1원리(#1) × 역전(#11) 교차**: 제1원리로 "노쇼는 태도 문제"를 해체하면 규칙 변경(자동 취소)이 나오고, 역전으로 그 규칙의 실패 모드를 돌리면 F6(취소석 폭주가 호출 병목을 만든다)과 F7(정지 누적)이 나온다. 두 결과를 합치면 **"유예 단축은 단독으로 시행하면 안 되고, 대기자 자동 승계 + 인증 시간 단일값 + 정지 대신 한도 소진과 반드시 한 묶음으로 시범해야 한다"**는 결론이 된다. 제1원리만으로는 "규칙을 바꿔라"까지, 역전만으로는 "정지 누적을 조심하라"까지만 도달하고, 묶음 조건은 교차에서만 나온다.
- **인지 무기고(최소 작용 #10 × 메커니즘 디자인 #24) × 실행 속도(문 분류)**: 두 렌즈는 "단계를 줄여라"와 "인증 단계를 넣어라"로 충돌하는데, 문 분류를 얹으면 해소된다. 인증 단계는 노쇼 감소 근거가 있고 벤더 설정으로 되돌릴 수 있는 Type 2이므로 유지하고, 근거 없는 단계(도서관 재선택, 중복 리마인더, 별도 확인 클릭)는 제거한다. **"근거 있는 마찰만 남긴다"**는 기준은 세 프레임을 겹칠 때만 정식화된다.

### 천재적 아이디어

모든 항목에 문 분류, "1개 관 시범 → 킬 기준", "틀렸다는 신호"를 붙였다. 자동 취소·페널티 계열에는 2차 효과 3줄이 있다.

1. **규칙 단일화 패키지 - 화면·문구는 한 글자도 바꾸지 않는다** [C1]
   - 설명: 전관 공통으로 입실 유예 1값(15~30분 사이 단일값), 외출 한도 1값, 대기자 호출 후 인증 1값(15분), 페널티는 "3회 7일 정지" 대신 "노쇼 1회 = 당일 예약 한도 소진"으로 전환. 공석 확인은 수기 폐지, 미인증 자동 취소로 대체. 안내문은 그대로 두고 규칙만 바꿔 효과가 규칙에서 오는지 분리 측정한다.
   - 엔진/모델: 제1원리 B2·B4·B6, 메커니즘 디자인 #24, 오컴 #59
   - 데이터 근거: 30분 자동 취소로 노쇼 22%→13%(ULiège, 대학 - 공공 검증 없음. 공공 병기: LA County 15분 유예 + 한도 산입, Nashville 15분 양도). 죽전 2시간 수기 확인 vs 1관 사서 약 4.6명(산출).
   - 실행 가능성: Medium - 1관 시범은 벤더 설정 범위면 Type 2, 전관 통일과 페널티 방식 전환은 운영규정 개정이라 Type 1.
   - 기대 효과: 시범 관 노쇼율 기준선 대비 -20% 이상(목표. 대학 상대 감소 41%의 절반을 공공 보수 가정). 죽전형 180석·15시간 관에서 노쇼 22%→13% 폭이 그대로 재현되면 좌석-시간 2,700/일 중 약 243 좌석-시간/일이 회복된다(산출: 2,700×0.09, 전 시간 만석 예약 가정, 외삽).
   - 2차 효과(필수): ① 취소석이 늘어 대기자 재배정 호출이 폭증한다 → 아이디어 3과 반드시 동시 시범. ② 수기 확인 폐지로 직원 부담은 줄지만 "자동 취소됐다"는 현장 이의 응대가 새로 생긴다 → 단말·문자에 취소 사유 1줄 자동 표기. ③ 고령층은 인증 절차 자체에 실패해 노쇼로 집계된다 → 정지가 아닌 한도 소진 방식으로 누적 정지를 구조적으로 없애고, 아이디어 4의 현장 창구를 선행.
   - 리스크 & 안티프래질: 공공에서 규칙에 노쇼가 반응하지 않을 수 있다(RAT 1순위 가설). 시범은 벤더 설정이라 되돌릴 수 있어 하방이 막혀 있고, 성공하면 전관 확산 상방이 열린다(옵셔널리티).
   - 문 분류: 1관 시범 Type 2 / 전관 규정 개정 Type 1
   - 1개 관 시범 → 킬 기준: 8주까지 노쇼율이 기준선 대비 -20% 미달이면 중단 검토. 60세 이상 이용자의 취소·한도 소진 건수가 시범 전보다 증가하면 즉시 중단.
   - 틀렸다는 신호: 자동 취소 도입 후 노쇼율은 그대로인데 "예약 자체를 안 한다"(예약 건수 급감)가 나타나면, 노쇼는 규칙 문제가 아니라 좌석 제공 방식(장시간 독점) 문제라는 반대 신호 2가 맞은 것이다.

2. **행동 프레임 안내 한 장 - 세 영역 공통 템플릿** [C2]
   - 설명: 조문 나열을 폐기하고 "당신이 할 것 3개 / 시스템이 자동으로 하는 것 3개 / 하지 않으면 잃는 것 1개" 고정 틀로 좌석·자료·프로그램 안내를 각 1장으로 재작성. 범위값("5~20분", "관별 상이") 금지. 숫자가 관마다 다르면 본문에 넣지 않고 관별 표로 분리.
   - 엔진/모델: 프레이밍 #35, 상대성 #7, 손실 회피 #31(잃지 않는 것 프레임), 한계효용 #47
   - 데이터 근거: 죽전 안내의 "30분 이내 인증"(경고/자동퇴실 불명), "5~20분(도서관 정책별 상이)". 리마인더 25.9% 중복 판단(대학, 공공 검증 없음).
   - 실행 가능성: High - 문구·게시물은 팀 자율 범위(OODA 진단에서 승인 3단계 이상이면 권한 매트릭스 먼저).
   - 기대 효과: 안내 관련 문의 -20% 이상(목표. 기준선은 2주 문의 태깅으로 확보). 예약 완료 단계 5 → 3(프로그램).
   - 리스크 & 안티프래질: 규칙이 통일되지 않은 상태에서 먼저 배포하면 F8(범위값 잔존)로 실패. 규칙 통일 항목만 본문에 싣고 나머지는 관별 표로 밀어내면 부분 배포가 가능하다(바벨: 확실한 결함 수정은 즉시, 불확실한 통합은 보류).
   - 문 분류: Type 2
   - 1개 관 시범 → 킬 기준: 안내문 2종(현행/행동 프레임)을 같은 관에서 2주씩 기간 분할 게시(Smoke Test). 8주까지 문의 건수 -20% 미달이면 문구 효과는 없다고 판정하고 규칙 계열로 자원 이동.
   - 틀렸다는 신호: 문의 건수는 줄었는데 노쇼·결원 지표가 전혀 움직이지 않으면, 이 후보는 "이해"만 바꾸고 "행동"은 못 바꾸는 것이다. 이때 문구는 유지하되 개선 예산은 규칙으로 옮긴다.

3. **대기자 자동 승계 체인 - 좌석·프로그램·자료 공통** [C3]
   - 설명: 노쇼 자동 취소·프로그램 취소·자료 미수령이 발생하면 시스템이 즉시 다음 대기자에게 배정하고 단일 인증 시간(15분) 안에 미응답이면 다음으로 넘긴다. 대기 순번을 이용자에게 노출한다. "반드시 취소해 주세요" 호소를 폐기한다.
   - 엔진/모델: 메커니즘 디자인 #24, 2차 사고 #58, 제1원리 B2
   - 데이터 근거: 죽전 "SMS 호출 후 5~20분", Nashville "15분 지연 시 양도", 1관당 프로그램 참가 22,366명(+5.1%)에 사서 +3.0% - 수동 결원 채우기는 격차가 벌어진다.
   - 실행 가능성: Medium - 벤더 기능 의존. 미지원 시 직원 수동 SMS(Wizard of Oz)로 1~2주 우회 시범 가능.
   - 기대 효과: 프로그램 결원 재배정 소요 시간 절반(목표. 기준선은 현행 전화 승계 소요를 2주 측정). 좌석은 아이디어 1의 2차 효과 ①을 흡수.
   - 2차 효과: ① SMS 발송량이 노쇼 건수에 비례해 늘어 비용·피로 증가 → 일 상한과 "호출 1회 = 문자 1회" 원칙. ② 대기 순번 노출이 "언제 될지 모른다"는 새 문의를 만든다 → 순번과 함께 "평균 승계 소요"를 2주 데이터 확보 후에만 노출. ③ 고령층은 15분 인증 창을 놓쳐 승계에서 밀린다 → 전화 응답도 인증으로 인정(아이디어 4 창구 연동).
   - 리스크 & 안티프래질: 취소석 폭주(F6)의 해법이자 원인이 될 수 있다. 상한 설정으로 하방을 막고, 자동화가 성립하면 수기 확인 인력이 다른 서비스로 옮겨가는 상방이 있다.
   - 문 분류: Type 2(설정·수동 우회) / 시스템 개조 필요 시 Type 1
   - 1개 관 시범 → 킬 기준: 8주까지 결원 재배정 소요가 기준선 대비 절반 미달이거나 대기자 SMS 일 발송이 상한을 반복 초과하면 중단 검토.
   - 틀렸다는 신호: 자동 승계된 좌석·자리의 2차 노쇼율이 1차보다 높으면, 대기자는 "잡아두기" 행동을 하고 있고 승계 체인이 노쇼를 옮기기만 하는 것이다.

4. **접근 채널 이원화 - 현장·전화 대행 창구(고령층·어린이 동반·비회원)** [C4, 선행 가드레일]
   - 설명: 세 영역 모두 온라인 외 경로를 정식 규칙에 명시. 시범 2~4주 동안 직원이 고령층 신청을 1:1 대행(컨시어지)하며 어디서 막히는지 기록 → 그 절차를 안내와 창구 표준으로 굳힌다. 전화 응답을 인증·확정으로 인정.
   - 엔진/모델: 제1원리 B3(법·권고), 역량의 원 #56, 반증 추구 #61
   - 데이터 근거: 인권위 2024.2.2 노인 디지털 접근 편의제공 의무화 권고, 달서구 성인 강좌 방문접수 병행(공공 사례). 서울 공공서비스예약 약 500여 서비스이나 고령층 민원 수치 미공개 - 효과 근거 없음, 의무 근거만 있음.
   - 실행 가능성: High(시범) / Medium(상시 인력)
   - 기대 효과: 고령층 예약 성공률 유지 이상(하한 지표). 아이디어 1·3의 킬 기준(고령층 정지·누락 증가)을 사전에 막는 보험.
   - 리스크 & 안티프래질: F3 역차별 민원. 대행 창구를 "정원 외 별도 배정"이 아니라 "같은 대기열에 다른 입구"로 설계하면 형평 논란이 줄어든다. 인력 비용은 아이디어 1의 수기 확인 폐지로 상쇄를 노린다.
   - 문 분류: Type 2(시범) / 상시 창구 인력 편성은 Type 1에 가까움
   - 1개 관 시범 → 킬 기준: 4주 컨시어지 후 대행 절차가 표준화되지 않으면(케이스마다 다르면) 상시 창구 대신 "전화 예약 대행"만 남기고 축소.
   - 틀렸다는 신호: 대행 창구 이용이 고령층이 아니라 온라인 회피 일반 이용자로 채워지면 채널 문제가 아니라 온라인 경로 자체(5단계)가 문제다.

5. **리마인더 감량 + 피크엔드 재배치**
   - 설명: 리마인더를 확정 문자 1회로 상한. 그 1회에 규칙 3줄(유예·취소 방법·잃는 것)과 취소 링크를 넣는다. 취소·노쇼 통보(엔드) 문구에 "이번 주 남은 예약 가능 횟수"를 붙인다. 가짜 긴급성 문구 금지 목록을 안내 규정에 명시.
   - 엔진/모델: 피크엔드 #37, 한계효용 #47, 손실 회피 #31
   - 데이터 근거: ULiège 리마인더 25.9% 중복 판단, 53.7% 제거 긍정(대학 - 공공 검증 없음. 공공 이용자층은 문자 의존도가 높을 수 있어 감량 폭은 시범으로 정한다).
   - 실행 가능성: High
   - 기대 효과: 문자 발송량 감소(정량은 현행 발송 횟수 확보 후), 노쇼율은 중립 가정(감량으로 악화되지 않는지가 검증 대상).
   - 리스크 & 안티프래질: 공공에서 리마인더 제거가 노쇼를 늘릴 수 있다. 1회 상한을 먼저 두고 0회는 시험하지 않는다.
   - 문 분류: Type 2
   - 1개 관 시범 → 킬 기준: 감량 후 4주 노쇼율이 기준선 대비 +5%p 이상 악화되면 즉시 복원.
   - 틀렸다는 신호: 감량 후 "문자를 못 받았다"는 문의가 늘면 공공 이용자층은 대학과 달리 리마인더를 중복이 아니라 안전장치로 쓰고 있는 것이다.

6. **자료 예약 안내 2단계화 + 상호대차 소요일 표기**
   - 설명: 도착 알림을 "도착"과 "보관 마감 전일" 2회로 고정(이 영역만 예외적으로 2회 - 수령 마감이 이용자 통제 밖의 물류에 걸려 있기 때문). 책바다·상호대차 신청 화면에 "평균 소요 N일"을 관별 실측값으로 표기. 미수령 시 다음 예약자 자동 승계(아이디어 3 연동).
   - 엔진/모델: 최소 작용 #10, 제1원리(가정 16·17 제거), 바퀴벌레 #20
   - 데이터 근거: 책바다 공공 1,123관 참여, 서울 신청 30%·제공 28%(편중 → 서울 외 관은 소요일이 길 가능성). 예약·상호대차 건수 총계 미공개(libsta 원자료 필요) - 이 영역은 기준선이 없다는 것 자체가 첫 발견이다.
   - 실행 가능성: Medium - 소요일 실측에 로그가 필요.
   - 기대 효과: 상호대차 문의 감소(정량은 기준선 확보 후). 보관 만료 미수령률 감소.
   - 리스크 & 안티프래질: 소요일 표기가 틀리면 신뢰를 잃는다. 범위값 금지 원칙과 충돌하므로 "최근 30일 평균 N일"처럼 산출 근거를 같이 쓴다.
   - 문 분류: Type 2
   - 1개 관 시범 → 킬 기준: 8주까지 상호대차 관련 문의가 줄지 않으면 표기 방식(평균 vs 최대)을 바꾸고, 그래도 안 되면 문의 원인은 소요일이 아니다.
   - 틀렸다는 신호: 소요일을 표기했는데 신청이 급감하면 안내가 아니라 서비스 자체(소요일이 너무 길다)가 문제다.

7. **프로그램 접수 방식 파일럿 - 우선순위 추첨 + 결원 자동 승계** (10% 실험)
   - 설명: 특정 강좌군에서만 선착순을 "신청 기간 접수 → 우선순위(신규 이용자·지역 주민·다자녀) 가중 추첨 → 결원 자동 승계"로 전환. 안내는 "언제까지 신청하면 되는가"로 바뀌어 접속 폭주 안내가 사라진다.
   - 엔진/모델: 제1원리(가정 10 제거), 메커니즘 디자인 #24, 유전적 부동 #19(파일럿 N 작음 경고)
   - 데이터 근거: "F5 새로고침" 공지(동래), 고려대 우선순위 추첨제(대학, 20년 만 개편 - 공공 전환 사례 미확인, 반대 신호 3), 오산 다자녀 우선순위(공공의 부분 보정 사례).
   - 실행 가능성: Low~Medium - 시스템 기능·운영규정 모두 필요.
   - 기대 효과: 접수 개시 시각 접속 집중 해소, 접수 관련 문의 감소(정량은 기준선 확보 후).
   - 리스크 & 안티프래질: 공공에서 추첨이 "운"으로 인식되어 형평 민원이 생길 수 있다(반대 신호 3의 미확인 원인). 강좌군 1개·1분기로 한정해 하방을 막는다.
   - 문 분류: Type 1
   - 1개 관 시범 → 킬 기준: 1분기 파일럿에서 참가율(확정자 중 실제 출석)이 선착순 강좌군보다 낮으면 중단. 형평 관련 민원이 선착순 대비 증가하면 중단.
   - 틀렸다는 신호: 추첨 도입 후 신청자 수 자체가 급감하면 이용자는 선착순의 "확정 즉시성"을 가치로 보고 있었던 것이다.

8. **결정 권한 매트릭스 - 문구·게시물은 팀 자율, 규칙은 1~2주 기한 결정**
   - 설명: OODA 자가 진단 결과 승인이 3단계 이상이면, 안내 개선안보다 먼저 "문구·게시물·FAQ·알림 타이밍 = 담당 팀 DRI 1명 결정", "유예·페널티·접수 방식 = 운영위 결정, 기한 1~2주, ADR 기록"을 문서화한다.
   - 엔진/모델: 실행 속도 문 분류·70% 규칙, 관료적 관성 #68
   - 데이터 근거: 3절에 직접 수치는 없다. 2절 제약(조례·벤더 계약이 변경 속도 제한)에서 도출. 근거 부족을 명시한다.
   - 실행 가능성: High(문서) / 조직 저항은 Medium
   - 기대 효과: 안내 문구 변경 리드타임 단축(기준선은 최근 3건의 변경 소요 일수).
   - 리스크 & 안티프래질: 권한 매트릭스가 문서로만 남을 수 있다. 첫 Type 2 결정 1건을 매트릭스대로 당일 처리해 선례를 만든다.
   - 문 분류: Type 2(문서) - 조직 결정은 되돌릴 수 있다.
   - 1개 관 시범 → 킬 기준: 4주 안에 매트릭스대로 처리된 Type 2 결정이 0건이면 매트릭스는 작동하지 않는 것이다.
   - 틀렸다는 신호: 권한을 위임했는데 문구 변경 건수가 늘지 않으면 병목은 승인이 아니라 담당자의 시간이다.

### Top 3 & 유니콘 평가

공공 부문이라 "유니콘 잠재력"의 축을 바꾼다: TAM → 확산 범위(관 수·이용자 수), 해자 → 제도화 잠금(규정에 박히면 되돌리기 어려운 이득), 타이밍 → 지금 하지 않으면 커지는 비용.

**1. 규칙 단일화 패키지(아이디어 1) + 대기자 자동 승계(아이디어 3)를 한 묶음으로**
- 선정 근거: 유일한 정량 노쇼 근거가 가리키는 지렛대이고, 편향 3(화면 수렴)에 대한 직접 해독제다. 교차 인사이트대로 둘은 분리 시범 불가.
- 확산 범위: 전국 공공도서관 1,328관(2025). 1관당 방문 173,000명/년, 프로그램 참가 22,366명/년(2024). 2024년 기준 관 수 1,296 × 22,366 ≈ 2,899만 프로그램 참가(산출)에 결원 승계가 닿는다.
- 제도화 잠금: 운영규정에 단일 수치가 들어가면 관별 재분산에 개정 비용이 들어 되돌리기 어렵다(좋은 방향의 비가역).
- 타이밍: 1관당 방문 +8.7%, 사서 +3.0%. 격차가 매년 벌어지므로 수기 의존 구조의 비용은 기다릴수록 커진다.
- 실행 로드맵: **30일** - 시범 관 1곳 선정, 노쇼 정의 고정, 최근 3개월 예약 로그 확보(없으면 4주 신규 집계), 벤더 설정 가능 항목 확인. **90일** - 유예 단일값 + 호출 인증 15분 + 정지→한도 소진 + 자동 승계를 한 묶음으로 8주 시범, 60세 이상 지표 주간 모니터. **1년** - 킬 기준 통과 시 운영규정 개정(Type 1, 결정 기한 2주)으로 전관 확산, 다음 지표로 좌석 제공 방식(장시간 독점) 재검토 착수.
- 킬러 가정: "공공도서관 이용자도 유예 자동 취소 규칙에 노쇼가 반응한다." 틀리면 노쇼율은 그대로이고 취소·재배정 부담만 늘어 직원 반발로 정책이 철회된다. 조기 감지: 시범 2주차 노쇼율이 기준선 ±2%p 안에 머무르면서 자동 취소 건수만 늘면 가정이 흔들리는 것이다. 4주차에 재판정.
- 리스크 시나리오: [고령층 정지 누적] 확률 중간 / 영향 치명 → 정지 방식 자체를 폐기(한도 소진)하고 창구(아이디어 4) 선행. [취소석 폭주 → 호출 병목] 확률 높음 / 영향 심각 → 자동 승계 동시 시범 + SMS 일 상한. [벤더 미지원] 확률 중간 / 영향 심각 → 수동 SMS 우회로 1~2주 검증 후 기능 요청.
- 바벨 구조: 시범은 설정 변경이라 하방이 막힌 90% 안전 자산, 성공 시 전관 확산·인력 재배치가 10% 공격 자산.

**2. 행동 프레임 안내 한 장(아이디어 2) + 리마인더 감량(아이디어 5)**
- 선정 근거: 비용이 거의 0이고 Type 2라 당일 결정 가능. 단 규칙 통일 항목만 본문에 싣는 조건부.
- 확산 범위: 1,328관 전체에 템플릿 그대로 이식 가능. 1관당 방문 173,000명이 접하는 안내.
- 제도화 잠금: 약함(문구는 누구나 되돌린다). 대신 템플릿을 안내 규정 부속서로 넣으면 중간.
- 타이밍: 즉시. 지연 비용은 매일 발생하는 "5~20분" 문의.
- 실행 로드맵: **30일** - 문의 유형 2주 태깅으로 기준선, 세 영역 한 장 초안, 이용자 5~10명 읽기 관찰(정성). **90일** - 같은 관 기간 분할 게시 8주, 문의 건수 비교. **1년** - 템플릿을 전관 안내 규정 부속서로.
- 킬러 가정: "문의의 상당 부분이 규칙을 몰라서 생긴다." 틀리면(문의가 규칙은 알지만 예외 요청·불만이면) 문구는 문의를 못 줄인다. 조기 감지: 2주 태깅에서 "규칙 질문" 비율이 30% 미만이면 이 가정은 약하다.
- 리스크 시나리오: [규칙 미통일 상태 배포] 확률 높음 / 영향 치명 → 통일 항목만 본문, 나머지 관별 표. [공공 리마인더 감량 역효과] 확률 중간 / 영향 관리 가능 → 1회 상한, +5%p 악화 시 복원.

**3. 접근 채널 이원화(아이디어 4) - 순위상 3위지만 실행 순서상 0번**
- 선정 근거: Top 1의 킬 기준(고령층 지표 악화)을 발동시키지 않기 위한 선행 조건이며, B3 법·권고 요건이다.
- 확산 범위: 노인 디지털 접근 권고(인권위 2024.2)는 전국 적용. 고령층 비율은 관별 로그로 확인(미확정).
- 제도화 잠금: 강함. 인권위 권고에 대응하는 절차로 규정에 들어가면 축소가 어렵다.
- 타이밍: 자동 취소 강화 전에 반드시. 순서가 바뀌면 F7이 현실화된다.
- 실행 로드맵: **30일** - 시범 관 고령층 신청 2~4주 1:1 대행(컨시어지), 막히는 지점 기록. **90일** - 대행 절차 표준화, 전화 응답을 인증으로 인정하는 설정, 창구 안내 한 장. **1년** - 상시 창구 인력을 아이디어 1의 수기 확인 폐지분으로 충당.
- 킬러 가정: "고령층 실패 지점은 소수의 반복 패턴이다." 틀리면(케이스마다 다르면) 표준화가 안 되고 상시 1:1 대행만 남아 인력이 모자란다. 조기 감지: 컨시어지 2주 기록에서 실패 유형 상위 3개가 전체의 70% 미만이면 가정이 약하다.
- 리스크 시나리오: [역차별 민원] 확률 중간 / 영향 관리 가능 → 같은 대기열에 다른 입구. [인력 부족] 확률 높음 / 영향 심각 → 전화 대행만 남기는 축소 옵션.

### Next Steps

**70% 정보 규칙 점검**(결정에 필요한 정보 8개 중 시나리오 A에서 현재 확보 0~2개 → 70% 미달):
1. 현재 노쇼율(위 정의로) 2. 안내 문의 유형·건수 3. 좌석 시스템 벤더·설정 권한 범위 4. 고령층 이용 비율 5. 운영규정·조례 개정 권한 6. 예산·기간 7. 대상 관 수·관종 8. 대기자·결원 처리 현행 방식.
→ **가장 빨리 얻을 정보 2개만 추가 수집**: (a) 최근 3개월 예약·취소·미입실·호출 로그(없으면 4주 신규 집계 시작), (b) 안내 문의 2주 태깅(규칙 질문 / 예외 요청 / 불만 / 기타). 나머지는 가정으로 진행하고 보고서 가정표에 박제.

**순서**
1. 이번 주: OODA 자가 진단 4문항 답하기(승인 단계 수 포함). 3단계 이상이면 아이디어 8을 먼저.
2. 이번 주: 노쇼율 정의 확정 문서 1장. 세 영역 별도 정의.
3. 2주 내: 시범 관 1곳 선정(로그 확보 가능·관장 재량 범위가 넓은 곳), 벤더 설정 가능 항목표 확보 → Type 1/2 라벨 확정.
4. 2~4주: 고령층 컨시어지 시작(Top 3, 순서 0번).
5. 4~12주: Top 1 묶음 시범 + Top 2 기간 분할 게시. 주간 지표: 노쇼율, 60세 이상 취소·한도 소진, SMS 일 발송, 문의 건수.
6. 8주 판정: 킬 기준 적용. 킬이면 24시간 내 피벗 검토(규칙 계열 전체 재평가 vs 좌석 제공 방식 재검토).
7. A/B 주의: 1개 관 트래픽은 통계적 유의성에 부족할 가능성이 크다. 로그 확보 후 MDE를 먼저 계산하고, 부족하면 이용자 5~10명 안내문 읽기 관찰로 대체. **"유의하지 않음 ≠ 효과 없음"**을 판정 문서에 명기.

**자원 배분 70-20-10**: 70% 확실한 결함 수정(범위값 문구 제거, 관별 불일치 표기 정리, 5단계 경로 축소) / 20% 규칙 변경 시범(Top 1 묶음, 컨시어지) / 10% 실험(추첨 파일럿). 블리츠스케일링은 해당 없음.
