## 핵심 인사이트 (5/10)
- **제1원리 x TRIZ 조건 분리 (가격 0 옵션)**: 무료·공공 자원의 노쇼·유령 점유는 안내 문제가 아니라 "가격 0 옵션" 문제다. 쓸 수 있는 통화는 돈이 아닌 시간(유예)·순위·이력이다
  적용 맥락: 무료 또는 공공 서비스에서 예약 부도·자원 공석이 문제인 문제 해결 유형
  근거: 기저 진실(옵션 가격 0, 손실 회피 2~2.5배)이 조건 분리의 재료를 지정해 타협안(일괄 유예 단축)을 걸러냈다 [s1 r1]
- **역전 x 실행 속도 (최상위 실패 모드를 MVT 정의에 넣기)**: 효과 지표가 없는 도메인에서는 Type 2 실험의 목적을 "기준선 측정"으로 재정의하면 실험이 실패할 수 없게 된다
  적용 맥락: 개선안 평가인데 도메인 기준 데이터(노쇼율 등)가 전무한 경우
  근거: 하방은 인건비, 상방은 기준선 확보+효과 판정이라는 옵셔널리티 구조가 된다 [s1 r1]
- **패턴 합성 반서사 x TRIZ 전체-부분 분리 (반서사를 프로브로)**: 비가역 반서사(제도 폐지)는 기각·채택이 아니라 부분 구역 프로브로 12주 검증한다
  적용 맥락: Type 1 결정에 반서사 후보가 있고 양방향 사례가 공존할 때
  근거: 양방향 사례 공존(인천중앙·마두 vs 중앙대)은 "조건에 따라 답이 갈린다"는 조건 분리 신호다 [s1 r1]
- **제1원리 x 역전 (회수와 억제 분리)**: 노쇼 페널티(이용정지)를 해체하면 자원 회수는 자동 취소·대기자 승계가 하고 정지는 억제만 남은 관습이다. 회수와 억제를 다른 도구로 갈라라
  적용 맥락: 무료·공공 예약의 부도 처리 규칙을 설계하는 문제 해결 유형, 특히 취약층(고령·다자녀 가구)이 있을 때
  근거: 역전이 억제 도구의 실패(정지·감점의 취약층 누적, 형평 보정 규칙과 같은 주체에서 상쇄)를 드러내 억제 단위를 개인·1회로 고정하게 했다 [s2 r1]
- **최소 작용 x 메커니즘 디자인 x 문 분류 (빼기 먼저)**: 이용자 단계를 빼는 개선(중복 알림·범위값·부탁 문장·직원 수동 처리 제거)은 Type 2, 더하는 개선(인증·계정 등록)은 시범·Type 1이다. 첫 분기 포트폴리오는 빼기 위주로
  적용 맥락: 안내·UX·규칙 개선안의 실행 순서를 정할 때
  근거: 최소 작용은 "줄여라", 메커니즘은 "넣어라"로 충돌하고, 문 분류가 시간 축을 넣어야 순서가 나온다 [s2 r1]
